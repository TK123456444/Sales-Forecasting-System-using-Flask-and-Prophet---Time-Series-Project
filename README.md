# 🚀 Sales Forecasting System Using Flask & Prophet | Time Series Forecasting

## 📌 Project Overview

**Sales Forecasting System Using Flask & Prophet** is an end-to-end **Time Series Forecasting** application that predicts future sales using historical business data. Built with **Facebook Prophet**, **Python**, and **Flask**, the system enables organizations to make data-driven decisions by forecasting future sales trends, seasonal patterns, and business demand.

This project demonstrates the complete lifecycle of a production-ready forecasting application, including data preprocessing, exploratory data analysis, model training, forecasting, visualization, and deployment through a user-friendly web interface.

---

## 🎯 Business Problem

Accurate sales forecasting is essential for effective business planning. Organizations often struggle with inventory management, production planning, staffing, and budgeting due to inaccurate demand predictions.

This project addresses these challenges by leveraging **Time Series Forecasting** to predict future sales, helping businesses:

* Optimize inventory levels
* Reduce operational costs
* Improve demand planning
* Increase revenue through data-driven decisions
* Support strategic business planning

---

## 💡 Solution

The application uses the **Facebook Prophet** forecasting model to analyze historical sales data and generate future sales predictions while automatically capturing trend, seasonality, and holiday effects.

The complete pipeline includes:

* Exploratory Data Analysis (EDA)
* Time Series Preprocessing

* Prophet Model Training

* Model Evaluation
